# Global Rules

- Do NOT add `Co-Authored-By` lines to commit messages
- Do NOT commit or push to git unless explicitly asked by the user

## Git Worktree

- Create worktrees on the same level as the main repo directory
- Name format: `<repo-name>--<branch-name-with-dashes>` (e.g. `webx.watchlab--feature-nextjs-standalone-output`)
- Replace slashes in branch names with dashes
